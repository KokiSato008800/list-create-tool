# 🗺️ Googleマップ店舗情報取得ツール

非エンジニアでもブラウザで開いてボタンをクリックするだけで、Googleマップから店舗情報を自動取得できるWebアプリケーションです。

## ✨ 特徴

- **完全無料**: Streamlit Cloudで無料デプロイ可能
- **ノーコード**: ボタン1つで実行
- **安定性重視**: リトライ機能、段階的タイムアウト設定
- **リアルタイム進捗表示**: プログレスバー、詳細ログ
- **Googleスプレッドシート連携**: 入力・出力ともにスプレッドシート

## 🎯 取得できる情報

- 店舗名
- カテゴリー
- 評価（星）
- レビュー数
- 住所
- 電話番号
- WebサイトURL
- 営業時間

## 📊 使用例

**入力（Googleスプレッドシート）**:

| エリア | 業種 | 開始順位 | 終了順位 |
|--------|------|----------|----------|
| 京都   | 居酒屋 | 41     | 200      |
| 金沢   | 焼肉 | 41       | 200      |

**出力**: 自動的に新しいスプレッドシートに保存

## ⚠️ 注意事項

### 利用規約

このツールはGoogleマップをスクレイピングします。Googleの利用規約では自動アクセスが制限されているため：

- 個人利用・教育目的に限定してください
- 大量のリクエストは避けてください
- 商用利用は推奨しません

### ブロックのリスク

- Googleマップからブロックされる可能性があります
- 待機時間を長くすることでリスクを低減できます
- ブロックされた場合は、しばらく時間を置いてください

### 大規模運用の場合

大規模かつ長期的な運用の場合は、**Google Places API（公式）**の使用を検討してください。
